# Basepoint-Analysis
Library for classifying orbits of mapping class group action on free homotopy classes of punctured torus


We study the action of the mapping class group of the punctured torus on its free homotopy classes of closed oriented curves by
realizing this action as that of the fundamental group's outer automorphism group. Using the Nielsen elementary generators
for the automorphism group of a free group, we generate orbit elements for a given conjugacy class using String edits.

We use the combinatorics of basepoint diagrams to classify the orbits in general for curves on the punctures torus
of a certain minimal self-intersection number.

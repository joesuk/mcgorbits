# Basepoint-Analysis
Library for classifying orbits of the mapping class group action on free homotopy classes of the punctured torus


We study the action of the mapping class group of the punctured torus on its free homotopy classes of closed oriented curves by
realizing this action as that of the fundamental group's outer automorphism group. Using the Nielsen elementary generators
for the automorphism group of a free group, we generate orbit elements for a given conjugacy class using String edits.

We use the combinatorics of basepoint diagrams to classify the orbits in general for curves on the punctured torus
of a certain minimal self-intersection number.

## History

This repository began as [joeysuk/Basepoint-Analysis](https://github.com/joeysuk/Basepoint-Analysis), the original Java basepoint-analysis code (now under `old/`).
It moved here, to [joesuk/mcgorbits](https://github.com/joesuk/mcgorbits), with the full commit history, when the Python and C++ orbit-counting code under `src/` was added.
